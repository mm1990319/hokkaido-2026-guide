# 北海道・秋の七日間

2026/10/21–10/27 北海道旅遊指南，依 Jacky 的 Notion 行程整理。網站提供每日行程、景點解說、Google Maps 路線導航、住宿資訊與離線閱讀。

## 使用

打開 GitHub Pages 網站後，選擇日期。行程卡顯示開始與結束時間；原資料沒有時間的項目會標成未定。景點卡片的「開始導航」會開啟 Google Maps，並以目前位置作為路線起點；路線方式依當日行程帶入，也可在 Google Maps 內調整。完成狀態與收藏只儲存在目前裝置的瀏覽器。首次連網載入後，網頁文字和站內圖片會供離線閱讀；Google Maps 路線與即時天氣仍需網路。

景點和行程時刻按原規劃的日本當地鐘面時間顯示；Notion 將它們記成台灣時區，網站因此比先前版本提前一小時。去程航班的起飛時刻是台灣時間、抵達時刻是日本時間；回程航班則相反。網站未包含訂位代號、付款資訊或護照等敏感資料。住宿的門禁與入住方式請以原訂房通知為準。

「旅途資訊」最上方內嵌每日沿途天氣，保留全天高低溫與最高降雨機率，並依日本時間顯示早上 08:00、中午 13:00、晚上 19:00 的逐時天氣、氣溫、體感溫度與降雨機率。降雨機率涵蓋雨雪，對應指定時刻前一小時；三個時刻不代表整個早午晚區間。Open-Meteo 的預報最長 16 天，出發前各日會陸續出現；尚未進入預報範圍的日期會顯示可查日期，不會借用當前天氣。缺少的逐時欄位會標示待更新，不會填入全天數值。天氣資料需要連網更新，快取 30 分鐘，日本日期換日後會重新取得預報；也可按「更新天氣」立即更新。

小樽 Airbnb 的精確位置未放入公開網站。首次使用時，點開 10/23「Airbnb Chech in」或「旅途資訊 → 住宿導航」，從原 Notion 住宿頁複製地址或座標並儲存。這項設定只留在該裝置的瀏覽器；換手機、清除網站資料後需重新設定。

租車取車和還車的營業所也可在對應行程內輸入確認單地址，避免把不同方案的營業所混淆。

## 更新內容

- 行程和景點資訊在 `data.json`。調整日期、時間、備註或導航目的地後，提交到 `main`，GitHub Actions 會重新部署。
- 若增加圖片，將檔案放進 `assets/photos/`，並更新 `data.json` 中對應景點的 `image.path`、來源與授權欄位。請確認公開使用權。
- 改動後遞增 `sw.js` 的 `CACHE` 版本字串，讓已安裝的離線網站取得新版。
- 修改程式或樣式時，同步更新 `index.html` 與 `sw.js` 的 `app.js`／`styles.css` 版本參數，避免瀏覽器混用新舊檔案。
- 網站使用相對路徑，可在 GitHub Pages 的專案網址下運作。設計在 `styles.css`，互動邏輯在 `app.js`。

## 出發前需確認

1. BR115 行程卡與航班表現在都顯示 **15:20 日本時間**起飛；仍請以電子機票確認航班是否異動。
2. 10/22 登別伊達時代村預計 **09:00** 抵達，距原備註的 09:30 忍者秀只有 30 分鐘；請預留停車、入園與步行時間，並查當日場次。
3. 10/26 迴轉壽司行程卡改為 **13:00 日本時間**，原筆記另寫 15:00–16:00 日本時間用餐，出發前請選定實際時段。
4. 千歲取還車營業所需依租車確認單，不可只憑「北海道女婿」品牌名稱導航。
